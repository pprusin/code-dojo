# State templates (`.dojo/`)

Plain Markdown, edited with normal file tools. Create only what you have evidence for.

## profile.md
```
Ask: always             # always | never (ask Dojo-or-normal at session start)
Level: basics           # zero | basics | intermediate
Language: python
Goal: <one line>
Language of replies: <e.g. Polish>
Notes: <how they like to learn, one line each>
```

## project-map.md
```
# Project map
- <module/file>: <responsibility>
Flow: <input> -> <step> -> <output>
```

## style.md
```
# Observed style
- Naming: ... (e.g. src/x.py)
- Errors: ...
- Tests: ...
```

## progress.md (append-only log)
```
## <date> <topic>
Rung: <highest ladder rung used, 1-6>
Done: <what the learner wrote>
Shaky: <what to bring back>
```
